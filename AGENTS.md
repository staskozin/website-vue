## Журнал согласий на аналитику

Сервер записывает согласия в JSONL-файл. Перед запуском приложения задайте
абсолютный путь к нему:

```sh
CONSENT_LOG_PATH=/var/lib/staskozin/consents.jsonl node .output/server/index.mjs
```

Родительский каталог и файл создаются автоматически. Пользователь, от имени
которого работает Node.js, должен иметь право создавать каталог либо записывать
в уже существующий каталог. Без `CONSENT_LOG_PATH` или при недоступном файле
сервер завершит запуск с ошибкой.

При обычной схеме `интернет → Caddy → Nuxt` Caddy передаёт реальный адрес
посетителя в `X-Forwarded-For`. Порт Nuxt не должен быть доступен из интернета
в обход Caddy.

## Настройки Яндекс Метрики

Код сайта отправляет только просмотры страниц без query-параметров и hash.
Перед публикацией в настройках счётчика № 96411226:

- включить ограниченный режим и маскировку полного IP-адреса;
- отключить Вебвизор, карты, аналитику форм и контентную аналитику;
- отключить автоматические цели и дополнительные настройки отслеживания;
- не включать электронную коммерцию.

Если на сайте появятся цели, их следует создавать и отправлять явно через
`reachGoal`, а не включать автоматическое определение целей.
