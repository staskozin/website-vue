# Добавление темной темы — суть решения

## Цель
Добавить на сайт полноценную темную тему и сделать переключение между светлой и темной темами в один клик.

## Основная идея
Решение построено на централизованной теме (`light`/`dark`) и CSS-переменных:
- состояние темы хранится в composable;
- тема применяется глобально через атрибут `data-theme` на `html`;
- все ключевые цвета берутся из переменных, а не из хардкода.

## Что реализовано
1. Создан composable `composables/useTheme.ts`:
- хранит текущую тему в `useState`;
- умеет переключать тему (`toggleTheme`);
- сохраняет выбор пользователя в `localStorage` (`theme`);
- при первом заходе берёт тему из `localStorage`, иначе из `prefers-color-scheme`;
- применяет тему через `document.documentElement.dataset.theme` и `colorScheme`.

2. Глобальная инициализация темы:
- в `layouts/default.vue` вызван `useTheme()`, чтобы тема применялась для всего приложения.

3. Глобальная палитра:
- в `assets/globals.css` добавлены переменные светлой и темной тем:
  - базовый набор в `:root`;
  - переопределения для dark в `:root[data-theme='dark']`;
  - fallback через `@media (prefers-color-scheme: dark)`.
- добавлены плавные переходы цвета текста и фона для `body`.

4. Переключатель в один клик:
- в `components/PageHeader.vue` добавлена кнопка `Theme: Light/Dark`;
- кнопка вызывает `toggleTheme` и работает на всех страницах.

5. Адаптация компонентов под переменные темы:
- `components/BaseSwitcher.vue`
- `components/InputIntPositive.vue`
- `components/RiceIngredients.vue`
- `pages/cv.vue`

Компоненты переведены с фиксированных цветов на глобальные переменные, чтобы интерфейс выглядел консистентно в обеих темах.

## Результат
- тема переключается мгновенно в один клик;
- выбор темы сохраняется после перезагрузки;
- светлая и темная темы работают на всех основных страницах и ключевых элементах интерфейса.
